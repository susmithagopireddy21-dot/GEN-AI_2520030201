# Week 1 – First LLM API Call

## Objective
In this week, I learned how to connect a Python program with a Large Language Model (LLM) and get responses by sending prompts through an API.

## What I Learned
- Got a basic understanding of Large Language Models.
- Learned how to connect Python with an LLM API.
- Understood how prompts are sent and responses are received.
- Learned how to set up a Python virtual environment.
- Understood how to install the required libraries.
- Learned why API keys and other sensitive details should be kept private.

## Files Used
- `main.py` – Contains the Python code used to make the LLM API call.
- `requirements.txt` – Contains the libraries required for the practical.
- `.gitignore` – Helps prevent unnecessary and sensitive files from being uploaded to GitHub.

## Steps to Run the Program

First, I created a virtual environment and installed the required packages. Then I executed the Python program.

```bash
python -m venv .venv
pip install -r requirements.txt
python main.py
```

## Learning Outcome
After completing this practical, I got an idea of how Python communicates with an LLM using an API. I also learned how to organise a Python project, install dependencies and handle API credentials safely.

## Conclusion
This practical helped me understand the basics of working with LLMs. It was a good starting point for learning how to build applications using Generative AI.
